# medsynth

Medical synthesis pipeline and knowledge retrieval system.

## Setup

This project is managed using [uv](https://docs.astral.sh/uv/).

### Prerequisites
- Python >= 3.12
- `uv` package manager

### Installation

```bash
uv sync
```

### Running

```bash
uv run python main.py
```

### Testing

```bash
uv run pytest
```
